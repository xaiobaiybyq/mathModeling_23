# 三问整合论文工作目录

先阅读[三问整合论文](最终论文_三问整合稿.md)。本稿由问题一实测特征结果、问题二已锁定预测模型报告、问题三已运行解释结果合成；文末保留附件1的100条特征汇总、附件3的30条预测、附件4的20条预测与解释。论文中的15条参考文献均先经网络检索，逐条来源与适用范围见[网络核验记录](参考文献网络核验.md)。

运行 python3 build_final_paper.py 可从三问源文件重建整合稿并核对内部链接、全量结果行数和参考文献编号。运行 python3 package_final.py 可重新打包三问技术附件与本目录论文，检查压缩包及50 MB体积。

本文件为可编辑的Markdown整合稿。用于竞赛正式提交前仍须按统一格式转成论文版式，核查公式、图片与跨页表格，并人工回听问题三自动时间定位中带警示的07、15、18号样本。不能把无标签附件3和附件4的预测当作真实准确率。
